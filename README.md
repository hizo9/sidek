# SIDEK

[![GitHub License](https://img.shields.io/github/license/hizo9/sidek)](https://github.com/hizo9/sidek/blob/main/LICENSE)
[![GitHub Top Language](https://img.shields.io/github/languages/top/hizo9/sidek)](https://github.com/hizo9/sidek)

Sensor-based waste detector for ricefield irrigation (subak) using YOLO11 and edge sensors.

## Installation

```bash
git clone https://github.com/hizo9/sidek.git
cd sidek
pip install -r requirements.txt
```

## Usage

```bash
python sidek.py
```
